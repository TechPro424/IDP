# Privacy Notice

Slop Filter does not collect or store any personal data. Audio features are generated locally and discarded after use. No video, audio, or text content is transmitted to external services except for the Bloom filter check, which only sends a hash of the prefix. All data is stored in the browser's local storage under the user’s account.

For more details, see the `LICENSE` and the code comments in `packages/extension` and `packages/edge`.
