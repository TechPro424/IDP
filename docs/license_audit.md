## Dataset register (empty)

When data is acquired, every source must be recorded here **before** use:

| Dataset / source | URL | License | Permitted uses | Retention | Attribution required |
|---|---|---|---|---|---|
| _(none)_ | | | | | |

Rules:

- No clip enters `packages/data/` without a row in this table.
- "Publicly viewable" is not a license. If a platform's terms forbid downloading, the clip
  is not collected, regardless of research purpose.
- Synthetic narration generated by a TTS provider is bound by that provider's terms; record
  which voice/model produced each clip so the split can stay generator-disjoint.
